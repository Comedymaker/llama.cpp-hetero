# HumanEval F16 速度与配置（截至 2026-10-02）

以下均使用 `layerskip-llama2-7B-F16.gguf`、greedy、4 线程、`-c 2048 -b 512 -ub 128`。本轮性能测试设置 `-n 128 --ignore-eos`，即强制生成 128 token；速度只统计生成阶段，不含 prefill。内存数字为 GiB。

## CPU Target：当前完整 HumanEval benchmark

使用纯 CPU `llama-completion`、mmap 和单层流式缓冲。表中速度是已完成题目的逐题算术平均，不是同一题的重复测量。

| 预算 | CPU 常驻层 | 已完成题数 | 平均生成速度 | 开跑前电池温度 30–<40°C 子集 |

| 8 GiB | 16/32 | 164/164 | 0.204 t/s | 59 题，0.210 t/s |
| 9 GiB | 18/32 | 113/164 | 0.237 t/s | 76 题，0.249 t/s |
| 11 GiB | 24/32 | 尚未开始 | — | — |

CPU 命令的主要参数为 `-dev none -ngl 0 --load-mode mmap --temp 0 --top-k 1 --ignore-eos --no-warmup --perf`。对应 `--model-resident-budget-mib / --runtime-reserve-mib`：8 GiB 为 `7430 / 1536`，9 GiB 为 `8066 / 1150`，11 GiB 计划为 `10500 / 764`，13 GiB 计划为 `12162 / 1150`。完整结果位于手机的 `/data/local/tmp/llama-exp-humaneval-full-budgets-linear-20260929/results.tsv`；9 GiB 的平均值会随剩余题目完成而变化。
