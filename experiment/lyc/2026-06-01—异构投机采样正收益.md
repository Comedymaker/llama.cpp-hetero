# 异构投机采样首次获得正收益

## 实验目的

验证 CPU draft 与 NPU target 的异构投机采样能否同时超过 NPU target-only 和 CPU target-only，并观察 draft 放置对不同任务的影响。

## 实验设置

- 日期：2026-06-01
- 模型：Qwen2.5-3B target + Qwen2.5-0.5B draft
- 对比组合：NPU target-only、CPU target-only、NPU target + CPU draft、CPU target + CPU draft、NPU target + NPU draft
- 任务：短 Prompt；CNN/DailyMail
- 扫描参数：短 Prompt 中包含 `draft-max=4` 和 `draft-max=16`
- 设备、量化格式、生成长度、重复次数和代码版本：原始记录未注明

## 实验结果

### 短 Prompt

| 组合 | Draft-max | 吞吐 | 接受率 | 对比 |
| --- | ---: | ---: | ---: | --- |
| 3B NPU target-only | 不适用 | 6.75 t/s | 不适用 | 基线 |
| 3B CPU target-only | 不适用 | 14.05 t/s | 不适用 | 基线 |
| NPU target + CPU draft | 4 | 18.06 t/s | 81.25% | NPU-only 的 2.7x，CPU-only 的 1.29x |
| NPU target + CPU draft | 16 | 16.49 t/s | 51.79% | 弱于 draft-max=4 |
| CPU target + CPU draft | 4 | 8.655 t/s | 76.562% | 慢于 CPU target-only |
| NPU target + NPU draft | 4 | 13.516 t/s | 83.333% | 快于 NPU-only，但弱于 CPU draft |

阶段性推测：短测中 NPU draft 与 NPU target 共享 HTP/RPCMEM 资源，可能抵消 draft 加速收益；尚未通过独立资源计数器验证。

### CNN/DailyMail

| 组合 | 吞吐 | 接受率 |
| --- | ---: | ---: |
| NPU target-only | 6.37 t/s | 不适用 |
| NPU target + CPU draft | 11.708 t/s | 72.727% |
| NPU target + NPU draft | 12.811 t/s | 72.727% |

CNN/DailyMail 上 NPU draft 略高于 CPU draft，与短 Prompt 结果不同。

## 实验结论

- 在当前短 Prompt 配置下，CPU draft + NPU target 首次同时超过 NPU-only 和 CPU-only，达到 18.06 t/s。
- CPU target + CPU draft 仍慢于 CPU target-only，进一步说明 NPU 的批量验证能力是本次正收益的重要组成部分。
- 最佳 draft 放置会随任务、上下文、窗口和硬件占用变化；NPU 资源争用仍是待验证推测，不能写成已确认原因。
