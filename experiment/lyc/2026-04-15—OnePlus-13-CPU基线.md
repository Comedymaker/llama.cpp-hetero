# OnePlus 13 CPU 基线

## 实验目的

建立不同模型规模和上下文长度下的 CPU prefill、decode 吞吐及峰值内存基线，为后续 GPU、NPU 和投机采样实验提供参照。

## 实验设置

- 日期：2026-04-15
- 设备：OnePlus 13
- 后端：llama.cpp CPU
- 模型：Llama-3.2-3B INT4；Qwen3.5-0.8B INT4
- 参数：`n_prompt=512`，`n_gen=128`，8 线程
- 上下文条件：短上下文、`d1024`、`d2048`
- 数据集、重复次数和代码版本：原始记录未注明

## 实验结果

### Llama-3.2-3B INT4

| 测试 | 吞吐 |
| --- | ---: |
| pp512 | 117.48 ± 1.51 t/s |
| tg128 | 24.59 ± 0.39 t/s |
| pp512 @ d1024 | 77.52 ± 0.59 t/s |
| tg128 @ d1024 | 19.77 ± 0.34 t/s |
| pp512 @ d2048 | 53.63 ± 0.18 t/s |
| tg128 @ d2048 | 15.56 ± 0.34 t/s |

- 模型大小：1.78 GiB；参数量：3.21B；峰值内存：4.34 GiB。
- 从短上下文增长至 `d2048` 时，prefill 下降约 54.4%，decode 下降约 36.7%。

### Qwen3.5-0.8B INT4

| 测试 | 吞吐 |
| --- | ---: |
| pp512 | 325.67 ± 6.03 t/s |
| tg128 | 59.72 ± 0.39 t/s |
| pp512 @ d1024 | 277.47 ± 1.75 t/s |
| tg128 @ d1024 | 56.28 ± 0.53 t/s |
| pp512 @ d2048 | 235.51 ± 4.14 t/s |
| tg128 @ d2048 | 51.20 ± 1.50 t/s |

- 模型大小：474.11 MiB；参数量：752.39M；峰值内存：1.20 GiB。
- 从短上下文增长至 `d2048` 时，prefill 下降约 27.7%，decode 下降约 14.3%。

## 实验结论

- 上下文增长会同时压低 prefill 和 decode 吞吐，3B 模型的降幅更明显。
- 这组 OnePlus 13、8 线程测试与当时“D6400、2 个小核、800 MiB 内存”的目标条件不同，不能直接比较。
