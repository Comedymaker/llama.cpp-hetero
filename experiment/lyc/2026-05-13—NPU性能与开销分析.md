# NPU 性能与开销分析

## 实验目的

解释移动 NPU 路径中“部分 MatMul 较快，但端到端推理较慢”的现象，分离计算、CPU fallback、调度和同步开销。

## 实验设置

- 日期范围：2026-05-13 至 2026-05-26
- 设备：原始记录未明确标注；结合上下文为移动端 HTP/OpenCL 测试
- 后端：HTP0、GPU OpenCL、CPU，以及 CPU + HTP / CPU + GPU 投机采样
- 5 月 13 日模型：Llama 1B Q4_0
- 5 月 19 日模型：Qwen3-0.6B Q4_0
- 5 月 20 至 26 日：Qwen3-0.6B Q4 的端到端剖析与真实 MatMul shape 微基准
- 完整命令、重复次数和代码版本：原始记录未注明

## 实验结果

### 2026-05-13：Llama 1B Q4_0

| 设备 | Prefill pp128 | Decode tg64 |
| --- | ---: | ---: |
| HTP0 | 184.69 ± 1.32 t/s | 40.45 ± 0.20 t/s |
| GPUOpenCL | 833.39 ± 21.57 t/s | 35.94 ± 0.16 t/s |
| CPU | 238.43 ± 2.45 t/s | 48.30 ± 2.90 t/s |

| 组合 | Decode 吞吐 |
| --- | ---: |
| CPU + HTP 投机采样 | 0.486 t/s |
| CPU + GPU 投机采样 | 3.496 t/s |

这一阶段的 HTP 后端尚未形成端到端优势，CPU + HTP 投机采样尤其慢。

### 2026-05-19：Qwen3-0.6B Q4_0

| 设备 | Prefill pp128 | Decode tg64 |
| --- | ---: | ---: |
| HTP0 | 187.40 ± 3.43 t/s | 22.95 ± 0.25 t/s |
| CPU | 579.55 ± 8.25 t/s | 95.49 ± 0.78 t/s |
| GPUOpenCL | 1193.30 ± 72.53 t/s | 49.64 ± 1.09 t/s |

在当时的上游 OpenCL/HTP 路径下，NPU 的 prefill 和 decode 均弱于 CPU。

### 2026-05-20 至 2026-05-26：从算子到全图

| 场景 | CPU-only | HTP 计算 | CPU fallback | HTP 路径总时间 |
| --- | ---: | ---: | ---: | ---: |
| tg16，每 token | 12.36 ms | 25.78 ms | 5.52 ms | 31.31 ms |
| pp16 | 57.20 ms | 124.17 ms | 22.22 ms | 146.43 ms |

真实 Qwen3-0.6B Q4 MatMul shape，batch=16：

| Shape（M,N,K） | 对应部分 | CPU | HTP | HTP 加速 |
| --- | --- | ---: | ---: | ---: |
| 16,2048,1024 | Q projection | 0.669 ms | 0.328 ms | 2.0x |
| 16,1024,1024 | K/V projection | 0.522 ms | 0.206 ms | 2.5x |
| 16,3072,1024 | FFN gate/up | 0.899 ms | 0.470 ms | 1.9x |
| 16,1024,3072 | FFN down | 0.874 ms | 0.334 ms | 2.6x |

- Batch=1 时，HTP 在部分 shape 上有 3-5x 优势；4096x4096 微基准约快 2.4x。
- OpenCL HTP 不支持当前模型的 Flash Attention；开启 `-fa 1` 后，加速的 fused attention 实际回退到 CPU。
- 前 3 层 Q4_1 `ffn_down` 和 Q6_K 输出层也会回退 CPU。
- 当时 HTP MatMul 支持 Q4_0、Q8_0、MXFP4 和 F16。

## 实验结论

- NPU 端到端慢并不等于 MatMul kernel 慢：部分真实 shape 的 HTP MatMul 可比 CPU 快约 1.9-2.6x。
- 当时 HTP backend 缺少足够的算子融合，细粒度 op 调用引入 call、RPC、同步和调度开销，CPU fallback 进一步吞掉 kernel 优势。
- 局部算子微基准不能直接作为端到端加速证据。
