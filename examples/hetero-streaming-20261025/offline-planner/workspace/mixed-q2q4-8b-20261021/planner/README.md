# 混精度平衡规划器 v1（离线）

2026-10-24：新增Q3与独立读取/复制路线的schema2规划入口，详见[MULTIBIT-20261024.md](MULTIBIT-20261024.md)。原默认Q2/Q4入口保持不变；复制Q2/Q3缺测时拒绝输出假片数。

后续已补齐Q2/Q3的7读1复制、CPU4、计算后驱逐锚点。新版staged默认成本源改为`staged-q23-calibration-20261024`的1176条真实逐层记录；当前8行搜索最接近的是全Q2，但仍1.384、未达到2%平衡带，见`multibit-staged-calibrated-20261024/n8/plan.json`。此前`multibit-final-20261024/staged-q23-calibration`是补测前缺测快照，不应当成当前状态。

目标先且只做：**让加载时间与“设备执行＋异步驱逐”的时间并集接近**。不靠人为逐一尝试全局Top-N找交点。重要性排名只决定某层既定片数中选择哪些片；不作为片数优化目标，也不声称质量收益可直接相加。

## 已实现

1. 从已有Top40/80/120/160/200/240原始日志提取3024条generation逐层观测。每条对齐同一层7个真实压缩tensor读取、设备执行、7次计算后驱逐及实际验证行数；不把Q4 carrier字节当I/O。载荷字节和Q4 tile数量必须与选片TSV严格一致，否则拒绝。
2. 建立逐层加载／执行／驱逐成本表。自变量为该层Q4片数与实际验证行数；使用中心化线性ridge模型，加载/驱逐片数斜率约束非负。它是受并发资源影响的经验模型，不是分别独立测出的每片硬件常数。
3. 模拟一层加载队列、A/B缓冲、下一层加载与当前层执行重叠、单独串行驱逐worker；驱逐必须在本层执行结束后开始。计算/驱逐取时间并集，最终驱逐排空单独报告。`--prefetch-ms`可描述L8提前读的时间，默认0。
4. 多起点坐标搜索各层0～32的整数Q4片数，默认限于每层已观察的最小/最大片数区间。**区间内未测整数属于插值；组合方案也未经实机测量**。默认不允许区间外外推；显式`--allow-extrapolation`才放开。全局最优不保证。
5. 输出可被现有mix-encode读取的`selection.tsv`、`cost-table.json`、`plan.json`逐层时间线；尚未自动部署/在线切换权重。
6. 现在还会自动输出`tree-initial/initial-profile.tsv`和manifest，供新前端以`LLAMA_TREE_INITIAL_PROFILE`加载。V1..64是完整Tail验证延迟曲线，C1..16是CPU完整动作初值。首次导出需保留六组原日志以估计固定主机残差；手机运行只读导出的文件，不需要原日志。

## 使用

在项目根目录执行（依赖Python和numpy）：

```powershell
python mixed-q2q4-8b-20261021/planner/planner.py --nodes 12 --validate
```

默认结果：`planner/output/`。`nodes`是**NPU实际验证输入行数，可能含pending token**，不是最终输出长度，也不是树深度。

成本表生成后直接复用，不再读取/重新拟合原始日志：

```powershell
python mixed-q2q4-8b-20261021/planner/planner.py --nodes 16 --cost-table mixed-q2q4-8b-20261021/planner/output/cost-table.json --output mixed-q2q4-8b-20261021/planner/example-n16
```

`--io-scale 1.1`表示在同一部署假设下，加载成本相对标定增加10%；不是精确模拟新硬件。`--prefetch-ms 50`描述首层可提前50ms。节点数超出观测范围默认拒绝，不把其他模型的曲线套进来。

## 验证与边界

10项自动检查：

```powershell
python -m unittest discover -s mixed-q2q4-8b-20261021/planner -p test_planner.py
```

`--validate`依次留出**整组Top-N实验**，用其余5组拟合、预测被留出组。当前加载相对误差均值约1.4%～6.3%，计算/驱逐并集约2.4%～4.7%，比例绝对误差约0.025～0.072。这不是对任意新选片组合的保证；各组只有单题单次，树形也未全部独立建模。

本版不模拟驱逐队列反压、节点以外的树形效应和新组合带来的资源争用变化；这些被当作标定噪声/验证误差。模拟中的逐层准备间隙来自已有trace，不包含CPU Draft，也不是完整端到端速度预测。最终驱逐排空与首层预取是边界，不隐藏在总比例中。

`--memory-budget-gib`现阶段会明确拒绝：没有可证明的峰值模型，不能拿3.68GiB采样峰值充当硬限制。Q4 carrier、普通DRAM暂存、Page Cache没有被当成随片数线性下降的占用。
